# Data Model: Casa Maestra Branding (077)

This feature stores no data. Its "entities" are the build-time values the app and the release scripts read. Each one lives in code or in `deploy/`.

## BrandDefinition (`lib/core/branding/brand_definition.dart`)

One deployment brand. It is immutable and const, and is defined once per brand in a const registry.

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `String` | `xbe` or `xbe.cm`. Unique in the registry. |
| `displayName` | `String` | `Mictlanix Business Essentials` or `Casa Maestra` |
| `seedColor` | `Color` | XBE `#ECAB03`, Casa Maestra `#00325F` |
| `light`, `dark` | `BrandColors` | Role overrides for `ColorScheme.fromSeed`, plus `SemanticColors` |
| `typography` | `BrandTypography` | Families and per-style metrics |
| `lockupAsset` | `String` | Login pane and documents |
| `lockupReversedAsset` | `String?` | Used in the dark theme. `null` means "use `lockupAsset`" (XBE). |
| `markAsset` | `String` | Nav header and watermark |
| `loginPane` | `LoginPaneStyle` | See below |

Rules:

- The registry is a `Map<String, BrandDefinition>`. `xbe` is the fallback for an empty, `mbe`, `xbe` or unknown ID (R1).
- Every role listed in contracts/brand-definition.md MUST be set for both brightnesses of a non-default brand.
- Product tokens (spacing, shape, elevation, density, breakpoints) are not fields. That is how FR-005 is enforced.

## BrandColors

| Field | Type | Notes |
| --- | --- | --- |
| `scheme` | role → `Color` overrides | Passed to `ColorScheme.fromSeed` |
| `semantic` | `SemanticColors` | The 12 shared roles (R3). XBE derives its accent from its scheme's tertiary roles. |

## SemanticColors (ThemeExtension, `lib/core/branding/semantic_colors.dart`)

`accent`, `onAccent`, `accentContainer`, `onAccentContainer`, `success`, `onSuccess`, `successContainer`, `onSuccessContainer`, `warning`, `onWarning`, `warningContainer`, `onWarningContainer`.

- It is reached through `Theme.of(context).semanticColors`. If the extension is missing, the getter falls back to XBE's values.
- `lerp` interpolates every field, the same way `BrandInk` does.

## BrandTypography

| Field | Type | Notes |
| --- | --- | --- |
| `displayFamily` | `String` | XBE `Archivo`, Casa Maestra `Bitter` |
| `textFamily` | `String?` | `null` keeps the base text theme (XBE). Casa Maestra uses `BrandRoboto`. |
| `labelUsesDisplayFamily` | `bool` | XBE `true` (Archivo labels), Casa Maestra `false` |
| `styles` | per-style override of `TextStyle` | Size, height, weight and letter spacing. XBE sets weights only, as today. |

## LoginPaneStyle

| Field | Type | Notes |
| --- | --- | --- |
| `followsTheme` | `bool` | XBE `false` (always dark), Casa Maestra `true` |
| `background`, `title`, `subtitle` | `Color?` | Fixed colors when `followsTheme` is false. Otherwise they come from the theme (`surface`, `onSurface`, `onSurfaceVariant`). |
| `accentBars` | `List<Color>` | XBE red, orange and gold. Casa Maestra uses one bar in theme `accent`. |

## StatusTone (`lib/core/widgets/status_chip.dart`)

An enum: `success`, `warning`, `error`, `info`, `neutral`, `promo`. Each value has a default icon and a (background, foreground) pair. See contracts/status-tones.md.

## NavGroup (existing, `lib/core/navigation/nav_destination.dart`)

The model is unchanged. `kNavigationTree` now holds Home plus four groups, with ids `operation`, `inventory`, `finance` and `system`. Each destination belongs to exactly one group (contracts/nav-sections.md).
